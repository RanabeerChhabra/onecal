Install in one account

Use a window with only that account signed in, such as a separate Chrome profile or an incognito window. Apps Script breaks when several Google accounts are signed in at once.
  1. Create the project

    Open script.google.com → New project. Click "Untitled project" and rename it Founders Meeting Agent.

  2. Show the settings file

    ⚙ Project Settings → tick Show "appsscript.json" manifest file in editor.

  3. Paste the two files

    Back in ‹› Editor, open appsscript.json, select all, and paste:

    Then open Code.gs, select all, and paste:

    Press ⌘S (Mac) or Ctrl+S (Windows) to save.

  4. Add the API key

    ⚙ Project Settings → Script properties → Add script property. Property: DEEPSEEK_API_KEY, value: the key from Ranabeer. Save.

  5. Run setup

    ‹› Editor → function dropdown in the toolbar → setup → Run → Review permissions → pick the account. If it says "Google hasn't verified this app", click Advanced → Go to Founders Meeting Agent (unsafe). It's our own script. Then click Allow.

    The log at the bottom should say ✅ Setup done.

  6. Preview, then switch on

    Pick dryRun → Run. The log lists what it would add, and nothing is written yet. If it looks right, pick enableSync → Run. From then on it checks every 10 minutes, and older meetings from the last 6 months fill in over the next hour or two.

Phone

No app to install beyond Google Calendar. First, on a computer: calendar.google.com → hover Founders — All Meetings → ⋮ → Settings and sharing → Event notifications → add 30 minutes and 10 minutes.

iPhone

  1. Install Google Calendar and sign in with your Ashoka account.
  2. ☰ → tick Founders — All Meetings.
  3. iOS Settings → Notifications → Google Calendar → Allow.
  4. Long-press the home screen → + → Google Calendar → Up next → Add Widget.

Android

  1. Google Calendar → ☰ → tick Founders — All Meetings. If it's missing: Settings → the calendar → Sync on.
  2. Settings → the calendar → Default notifications: 30 and 10 min.
  3. Long-press the home screen → Widgets → Calendar → Schedule.

If something goes wrong

"This app is blocked"

Ashoka doesn't let the script read Gmail. Tell Ranabeer; there's a ready-made email to Ashoka IT. The other accounts keep working in the meantime.

"Could not find the calendar"

Open the share email in that account and click Add this calendar, then run setup again. If no email came, add the Script property SHARED_CALENDAR_ID with the ID printed by setup in founders@tryamp.in, and run setup again. If it then says "no access", check that step 2 was done.

"can only view the shared calendar"

Step 2 isn't done yet. Once it is, Anshul runs setup again in founders@tryamp.in.

Want to stop one account?

In that account's script, run removeThisAccount. It stops syncing and removes upcoming meetings only that account knew about.
